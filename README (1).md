## 1\. What This Service Does

The CoOwn AI/ML Service is a Python FastAPI microservice that powers four
AI features in the CoOwn platform:

|Feature|Endpoint|Sprint Column|
|-|-|-|
|Property valuation|`POST /predict/valuation`|Col 1 \& 2|
|AI property brief|`POST /predict/brief`|Col 3|
|Smart pool matching|`POST /predict/pool-match`|Col 3|
|Ownership forecaster|`POST /predict/forecast`|Col 4|
|Model accuracy report|`GET /model/accuracy`|Col 4|

It runs as a **separate process on port 8000**.
The Node.js backend calls it over HTTP — the frontend never talks to it directly.

## 5\. First-Time Setup

Do these steps in order. Only needs to be done once.

### Step 1 — Create your virtual environment

Open a terminal in your project folder:

```bash
# Windows
python -m venv venv
venv\\Scripts\\activate

# Mac / Linux
python -m venv venv
source venv/bin/activate
```

You know it worked when you see `(venv)` at the start of your terminal line.

### Step 2 — Install all packages

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

This takes 2-4 minutes. Do not close the terminal.

### Step 3 — Create your .env file

```bash
# Windows
copy .env.example .env

# Mac / Linux
cp .env.example .env
```

Open `.env` and set your values:

```
COOWN\_API\_KEY=coown-dev-key-change-in-prod
ANTHROPIC\_API\_KEY=your\_key\_here\_or\_leave\_blank
RATE\_LIMIT\_RPM=60
ALLOWED\_ORIGINS=\*
```

### Step 4 — Create the logs folder (if it does not exist)

```bash
# Windows
mkdir logs

# Mac / Linux
mkdir -p logs
```

### Step 5 — Train the model (IMPORTANT — must do before starting server)

```bash
python model/train.py
```

You will see:

```
⏳  Training valuation model …
✅  Model trained!
MAE   :    ₦8,200,000
R²    :  0.9412
MAPE  :  12.3%
💾  Model saved to disk.
```

This creates 4 `.pkl` files in the `model/` folder.
The server will not start without them.

### GET /health

No auth required. Used by backend to check if AI service is online.

**Response:**

```json
{
  "status": "ok",
  "model\_loaded": true
}
```

### POST /predict/valuation

Called by the backend when a new property listing is created.
The `display` field goes on every listing card in the frontend.

**Request:**

```json
{
  "location":      "Lekki Phase 1",
  "property\_type": "flat",
  "bedrooms":      3,
  "size\_sqm":      120,
  "age\_years":     5
}
```

**Response:**

```json
{
  "status":        "ok",
  "display":       "Est. ₦7.2M – ₦8.8M",
  "estimated\_min": 7200000,
  "estimated\_max": 8800000,
  "mid\_point":     8000000,
  "confidence":    "High",
  "currency":      "NGN",
  "warnings":      \[]
}
```

**Supported locations:**
Banana Island, Ikoyi, Victoria Island, Lekki Phase 1, Lekki Phase 2,
Ajah, Ikeja GRA, Magodo, Surulere, Yaba, Maitama Abuja, Wuse 2 Abuja,
Asokoro Abuja, Gwarinpa Abuja, Port Harcourt GRA

**Supported property types:**
flat, duplex, detached house, semi-detached, terrace, bungalow, land

Unknown locations/types fall back gracefully with a warning in the response.

**Request:**

```json
  "property\_type": "flat",
  "bedrooms":      2,
  "size\_sqm":      85,
  "price\_ngn":     9500000,
  "amenities":     "24hr power, borehole, security"
}
```

**Response:**

```json
{
  "status":        "ok",
  "brief":         "A thoughtfully designed 2-bedroom flat in the heart of Yaba,
```

## 8\. Backend Integration Guide (Node.js)

### Files to add to the Node.js project

From the Day 2 integration package, add these to `src/`:

```
src/
├── types/
│   └── property.types.ts      ← TypeScript interfaces
├── services/
│   ├── ai.service.ts          ← calls Python /predict/valuation
│   └── property.service.ts    ← property CRUD + valuation seeding
└── routes/
    └── property.routes.ts     ← Express router for /api/properties
```

### Environment variables needed in the Node.js .env

```
AI\_SERVICE\_URL=http://localhost:8000
AI\_SERVICE\_KEY=coown-dev-key-change-in-prod
```

The key in `AI\_SERVICE\_KEY` must match `COOWN\_API\_KEY` in the Python `.env`.

### How the backend uses the AI service

When a new property is created via `POST /api/properties`, the backend
automatically calls `POST /predict/valuation` on the AI service and stores
the result in the `ai\_valuation` field of the property record.

If the AI service is down, the listing still saves — it just won't have a
valuation badge until the service comes back online.

### Register the router in app.ts

```typescript
import propertyRoutes from "./routes/property.routes";
app.use("/api/properties", propertyRoutes);
```

### Supabase (replacing in-memory store)

In `property.service.ts`, replace the `propertyStore` array with:

```typescript
import { createClient } from "@supabase/supabase-js";
const supabase = createClient(process.env.SUPABASE\_URL!, process.env.SUPABASE\_KEY!);

// Get all properties
const { data } = await supabase.from("properties").select("\*");

// Insert new property
await supabase.from("properties").insert(property);
```

## 12\. Troubleshooting

### "No such file or directory: model/valuation\_model.pkl"

You have not trained the model yet. Run:

```bash
python model/train.py
```

### "This site can't be reached" on localhost:8000

The server is not running. Run:

```bash
uvicorn main:app --reload --port 8000
```

### "pip install" fails with Python version errors

You are on Python 3.13. Use the updated requirements.txt which has
compatible package versions. Run:

```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### AI brief returns "fallback" instead of "claude-ai"

Your Anthropic API key is missing or wrong. Open `.env` and set:

```
ANTHROPIC\_API\_KEY=your\_actual\_key\_from\_console.anthropic.com
```

The fallback brief is still clean and usable — this is not a broken state.

### "401 Unauthorized" on any endpoint

You are not sending the API key header. Add to your request:

```
X-API-Key: coown-dev-key-change-in-prod
```

### "429 Too Many Requests"

You have hit the rate limit (60 requests/minute). Wait 60 seconds or
increase `RATE\_LIMIT\_RPM` in your `.env`.

### Backend cannot reach AI service

Check that the Python server is running on port 8000.
Check that `AI\_SERVICE\_URL=http://localhost:8000` is in the Node.js `.env`.
Check that `AI\_SERVICE\_KEY` matches `COOWN\_API\_KEY` in the Python `.env`.
